# CineReserve – Movie Ticket Booking System

## Overview

CineReserve is a web-based application designed to simulate a movie ticket booking system. The project demonstrates the implementation of the Model-View-Controller (MVC) architecture using Spring Boot and MySQL.

The system allows users to view available seats for a movie show and perform basic booking operations such as reserving, booking, and releasing seats.

---

## Features

* Display of available seats for a movie show
* Seat reservation and booking functionality
* Real-time update of seat status
* Simple and interactive user interface
* Backend integration with MySQL database

---

## Technologies Used

* Java (Spring Boot)
* Spring Data JPA
* MySQL
* HTML, CSS, JavaScript

---

## Architecture

The project follows the MVC (Model-View-Controller) design pattern:

* **Model**: Represents the data and business logic of the system
* **View**: Provides a user interface for interaction
* **Controller**: Handles user requests and coordinates between Model and View

This separation ensures better maintainability and scalability of the application.

---

## Database

The application uses a MySQL database to store data related to movies, theatres, screens, seats, and bookings. Relationships between entities are maintained to ensure data consistency.

---

## How It Works

Users can view seat availability and perform actions such as reserving or booking seats. The system updates seat status dynamically and reflects changes in the interface.
